# Catherine's Hobbies & Interests Website

A responsive personal website built with HTML and CSS.

## Files
- `index.html` — page content and structure
- `style.css` — colours, layout, typography, cards, and responsive design

## Preview locally
1. Keep `index.html` and `style.css` in the same folder.
2. Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **new public repository** (for example, `catherine-hobbies-website`).
2. Upload both `index.html` and `style.css` to the repository's main/root folder.
3. Open the repository's **Settings**.
4. Select **Pages** from the left menu.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then save.
7. Wait a few minutes and refresh the Pages settings. GitHub will show your website address, usually in the form `https://YOUR-USERNAME.github.io/catherine-hobbies-website/`.

Remember: replace `YOUR-USERNAME` with your actual GitHub username. The exact link is only active after GitHub Pages is enabled.
